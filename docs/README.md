## Источники

* `ref/TIP — макет интерфейса.pdf` — утверждённый макет (6 экранов).
* `ref/web/` — рабочая демо-версия (Go+Fiber, React). Берём UI-токены, рендер билета, идею хаба; переписываем всё, что помечено в плане как «упрощение».
* `ref/tip/` — устаревшее десктоп-приложение (Qt/C++, GPLv3). Используем **только как перечень функций**. Код и БД не переносим.

## Журнал решений

| # | Решение | Кто принял |
|---|---|---|
| D1 | Backend — Go (последний стабильный), **монолит** | заказчик/тимлид |
| D2 | HTTP: **net/http + chi**, WebSocket: **coder/websocket** (вместо Fiber) | согласовано 2026-11-07 |
| D3 | БД PostgreSQL, миграции **goose**, SQL через **database/sql** (+ pgx stdlib), без ORM | заказчик/тимлид |
| D4 | Роли: `admin`, `worker`. Работник видит **активные и завершённые** проекты (завершённые read-only) | согласовано 2026-11-07 |
| D5 | Аккаунты создаёт и пароли сбрасывает только админ, без e-mail/SMTP | согласовано 2026-11-07 |
| D6 | Логи и метрики хранятся **3 дня** по умолчанию (диск 10 ГБ), настраивается (`OBS_RETENTION_DAYS`, 3–5) | заказчик/тимлид |
| D7 | Фронтенд — Vite + React + TypeScript (как в демо), оптимизация под macOS/iOS Safari | заказчик/тимлид |
| D8 | Аутентификация — **JWT HMAC-SHA256**: access (15 мин, в памяти SPA) + refresh (30 дней, httpOnly-cookie, ротация); серверных сессий нет | согласовано 2026-11-07 |
| D13 | **Токены хранятся только в Redis, в Postgres их нет**: refresh allow-list (`rt:*`), отзыв цепочек, чёрный список access (`bl:jti`), отсечки пользователей (`bl:user`) — всё с TTL; мгновенный отзыв при выходе, деактивации, смене роли/пароля; Redis (не Valkey), при его недоступности проверка access пропускается с алертом (`open`) | согласовано 2026-11-07 |
| D9 | Метрики: **Prometheus**; логи: **Loki + Vector**, UI — **Grafana вместо Kibana** (метрики и логи в одном окне). ELK отклонён: на сервере 2 ГБ RAM и HDD | согласовано 2026-11-07 |
| D14 | **Динамические роли в БД** (создаёт и назначает админ в админ-панели): права — каталог в коде, роль — набор прав; **права едут в access-JWT**, проверка без БД на запрос; смена ролей — эпоха прав + `TOKEN_STALE` | согласовано 2026-11-07 |
| D15 | Refresh: при обновлении выдаётся **новая пара**, старый refresh «сжигается» в Redis (`SET NX`), повторное предъявление закрывает цепочку | согласовано 2026-11-07 |
| D16 | **OpenAPI 3.1 contract-first + Swagger UI** (`/api/docs`), кодогенерация DTO для Go и TS | согласовано 2026-11-07 |
| D17 | Пароли: только необратимый хэш argon2id + pepper; создание/сброс генерируют новый пароль, смена при первом входе **рекомендуется** | согласовано 2026-11-07 |
| D18 | Фронтенд: **красиво анимирован, интерактивен и интуитивно прост** (motion-токены, отмена вместо подтверждений, юзабилити-тест); таблица участников — **№ · Имя · Номер телефона**, без статуса; занятая строка блокируется и обводится цветом редактирующего с подсказкой при наведении | согласовано 2026-11-07 |
| D19 | **Диск сервера — 10 ГБ:** аудит хранится 30 дней и не более 100 000 строк, потолок картинок 800 МБ, 3 дампа БД + 1 снимок uploads, дисковый бюджет по статьям (`05-observability.md`, 6.1) | согласовано 2026-11-07 |
| D10 | **Сервер (факт):** 2 vCPU, **2 ГБ RAM**, HDD 10 ГБ; стек подобран под него: контейнеры ≈ 0,96 ГБ RAM (≈ 1,3 ГБ с ОС), `mem_limit` на каждый, zram | согласовано 2026-11-07 |
| D11 | Backend строится по **Clean Architecture** с цепочкой **`handler → service → repository`** (+ `domain`, `platform`; пять папок в `internal`); `service` не импортирует `repository`, правило проверяется в CI | согласовано 2026-11-07 |
| D12 | Логи: **zerolog** (+ diode, сэмплинг) вместо `log/slog`; внутренние слои не логируют | согласовано 2026-11-07 |
| D20 | Ответы Q2–Q10: работник видит завершённые проекты; импорт — админу и ролям с правом `participant.import`; печать — константа 7×4 см как в десктопе; интерфейс ru + uz (выбор в профиле); темы тёмная (по умолчанию) и светлая; Q9 — по умолчанию | согласовано 2026-11-07 |
| D21 | Бэкапы вне сервера: `rclone` + шифрование (`crypt`), провайдер подключается конфигом (рекомендация — S3-совместимое облако в РФ или pull на ПК владельца) | согласовано 2026-11-07, провайдер — в Фазе 8 |
| D22 | Алерты без Telegram (недоступен с сервера в РФ): Grafana alerting → e-mail (SMTP) / webhook + красная плашка «Состояние» в админ-панели | согласовано 2026-11-07 |
